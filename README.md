# Rubik's Cube Android wrapper

Android Studio project that opens the published Rubik's Cube website in a WebView.

Mobile fixes included in the latest website build:
- native touch-only carousel controls on phones/tablets
- native touch-only camera controls in the 3D game
- no WebView scrolling/zooming
- PWA fullscreen request plus Android immersive system-bar hiding
- original Rubik's Cube launcher icon

The app is locked to landscape and keeps the screen awake. The website still needs an internet connection because the current app URL is the GitHub Pages site.
